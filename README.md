# 分散創造（Bunsan Souzou）

**描く。分岐する。素材と拡張機能は、誰にも消されない。**

「分散創造」は、Git のような分散バージョン管理と、素材・拡張機能の P2P 配布を組み込んだ、イラスト・漫画制作ツールです。

> [!NOTE]
> 現在は**構想段階**です。まだ動くソフトウェアはありません。
> 詳しい仕様は [要件定義書](docs/requirements.md) を参照してください。

## 特長

### 🎨 本格的なイラスト・漫画制作
CLIP STUDIO PAINT やメディバンペイントのように、筆圧対応ブラシ、ラスター／ベクターレイヤー、選択範囲、縦書きテキスト、定規などを備えた制作ツールを目指します。

### 🌿 Git のように履歴を管理
- 作品の状態を**履歴更新**で**履歴**として保存し、いつでも過去に戻れる
- **履歴候補上げ**で、変更のうち記録するものを選べる
- **履歴系統**を**分岐**して別案を試し、良いものを**統合**できる
- 履歴どうしの違いを、重ね合わせや並べ表示で**目で見て比較**できる
- レイヤー単位で履歴統合するので、複数人で同じ作品を同時に描ける
- 共同制作者とは**初回ダウンロード**・**継続ダウンロード**・**アップロード**で作品をやりとりできる
- ネットワークなしでも全機能を使える

Git に慣れていない人にも伝わるよう、Git の用語ではなく次の名称を使います。

| 分散創造 | Git |
| --- | --- |
| 初回ダウンロード | クローン |
| 履歴 | コミット（記録そのもの） |
| 履歴候補上げ | ステージング（add） |
| 履歴更新 | コミット（記録する操作） |
| 履歴系統 | ブランチ（流れそのもの） |
| 履歴分岐 | ブランチ（作る操作） |
| アップロード | プッシュ |
| 継続ダウンロード | プル |
| 履歴統合 | マージ |

対象が履歴・履歴系統だと明らかなときは、履歴分岐・履歴統合を「分岐」「統合」と略します。

### 🌐 素材・拡張機能を中央サーバーなしで配布
- ブラシ・トーン・パターン・コマ割りテンプレートなどの**素材**と、機能を追加する**拡張機能**を、Winny や暗号資産のようにピア同士で直接やりとりします
- 運営会社・審査機構・アカウント登録がないため、第三者が素材や拡張機能を一方的に削除・公開停止することが構造的にできません
- 配布物はハッシュ値で識別され、改ざんを検出できます。作者の電子署名で本人が公開したものであることを確かめられます
- 拡張機能は権限を制限した環境（サンドボックス）で動き、導入や更新のたびに利用者の同意を求めます
- 開発者自身も、後から制限を追加したり、遠隔で消したりする手段を持ちません
- 作品そのものは P2P 配布の対象外です

### 📖 漫画モード：コマ割りとコマ内容を別々に管理
漫画モードでは、**コマ割り**と**コマの中身**を別々のデータとして、それぞれ独立に履歴管理します。

```
作品（漫画）
├── ページ構成履歴     … コマの形・配置・読み順
└── コマ内容履歴       … 各コマの絵・セリフ・効果
```

- ネームを直してコマの形を変えても、描き終えた絵はそのまま残る
- 同じ作画のまま、コマ割り案 A と案 B を並べて比べられる
- 作者がコマ割りを直している間に、アシスタントがコマの背景を描ける

## ご利用にあたって

本ツールが保証するのは、中央管理者がいないという**技術的な構造**です。**法律の適用を免除するものではありません**。利用者は、自分のいる国・地域の法律に従う責任を負います。

また、一度公開した素材・拡張機能は他の利用者の端末に複製されるため、作者本人でも完全に取り消すことはできません。公開前によくご確認ください。

詳しくは [要件定義書 6 章「検閲耐性の設計方針と限界」](docs/requirements.md#6-検閲耐性の設計方針と限界) を参照してください。
