# 開発者の思想信条

表現規制はすべて
- 行政や企業が表現規制をすること自体に反対(特に外資のクレジットカード会社が表現規制に加担することは許すべきではない)
- AI推進派。AIによる画像・動画・音楽生成は特別に規制されるものではない。学習元が何であれ、著作権に反した生成物を公開しない限り問題ない。
- 人間の創造性がなくともAI・ロボットによって作品が量産される以上、知的財産権や著作権は意味のないものになりそうだと思っていて2060年くらいまでにはなくなってもよいと思っている。ただし、2026年現在で違反するのは許されてはならない。
