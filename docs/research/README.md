# 調査レポート

先行事例や技術の調査結果を置く場所です。構想（[vision.md](../vision.md)）や設計判断の根拠として使います。

## 書き方

- 出典には、判決文、官公庁・公的機関の公表資料、査読付き論文、公式の仕様書・文書などの一次資料を使います。
- 引用する前に原文を取得し、引用する文が原文に存在することを照合します。引用は「」内に原文のまま書きます。
- 出典が述べる事実と、本プロジェクトとしての解釈は、節を分けて書きます。
- 一次資料で確認できなかった事柄は「確認できなかった」と明記し、事実として書きません。
- 参考文献には、著者・題名・掲載先・年・URL・アクセス日を書きます。
