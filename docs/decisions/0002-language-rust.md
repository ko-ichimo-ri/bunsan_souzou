# 開発言語に Rust を使う

- 日付：2026-09-24
- 状態：採用

## 背景

描画・分散バージョン管理・P2P 通信を 1 つのアプリケーションで扱う。構想では 8K 解像度・多数のレイヤーを扱う性能も求めている（[vision.md](../vision.md) NF-01）。

## 判断

開発言語に Rust を使う。

## 理由

- C/C++ 並みに高速で、構想の性能要件に届く。
- 所有権の仕組みにより、メモリ関連の不具合がコンパイル時に見つかる。
- Rust 製の P2P ライブラリ（Iroh・rust-libp2p）が充実している。
- Windows・macOS・Linux 向けに同じコードからビルドできる（NF-04）。

## 影響

- 書き方の決まりが厳しく、TypeScript などに比べて最初の立ち上がりに時間がかかる。
- 開発メンバーが Rust 初心者のため、[Rust 技術ガイド](../guides/rust.md) を作り、つまずいた点を随時追記する。
