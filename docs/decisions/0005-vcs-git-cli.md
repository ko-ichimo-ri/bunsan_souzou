# 分散バージョン管理は git コマンドを呼び出して実現する

- 日付：2026-09-24
- 状態：採用

## 背景

分散バージョン管理（履歴更新・分岐・統合など）を試作品に入れたい。Git がインストールされている前提でよい。

## 判断

アプリケーションから `git` コマンドを呼び出して、分散バージョン管理を実現する。Rust では標準ライブラリの `std::process::Command` を使う。

## 理由

- Git の機能をそのまま使えるので、実装量が最も少ない。
- 作品フォルダがそのまま Git リポジトリになり、アプリケーションの外からも `git` コマンドで確認・操作できる。
- Git の Rust 実装（gix）や libgit2 のバインディング（git2）は、必要になった段階で移行を検討できる。

## 影響

- 利用者の PC に Git のインストールが必要。
- 画面の用語（履歴更新・分岐など）と `git` のコマンドの対応を、アプリケーション側で持つ。
