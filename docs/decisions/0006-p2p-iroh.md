# P2P 配布に Iroh を使う

- 日付：2026-09-24
- 状態：採用

## 背景

素材を中央サーバーなしで配布する。構想では、配布物をハッシュ値で参照し、1 つでもピアが保持していれば取得できることを求めている（[vision.md](../vision.md) F-P2P-01・F-P2P-03）。

## 判断

P2P 配布に Iroh（ファイルの受け渡しには iroh-blobs）を使う。

## 理由

- データをハッシュ値（BLAKE3）で指定して、端末間で受け渡す機能を持つ。構想の要件にそのまま合う。
- Rust 製で、本プロジェクトの言語と一致する。
- 端末どうしの直接接続を試み、つながらない場合は中継サーバーを経由する仕組みを持つ。
- rust-libp2p より機能が絞られていて、試作に取り入れやすい。

## 影響

- 標準の中継サーバー・ピア発見の仕組みには、Iroh の開発元（n0）が運営するサーバーが含まれる。構想の「単一障害点を持たない」（F-P2P-02）を満たすには、後の版で自前の中継サーバーや DHT によるピア発見を検討する。
- 試作では、まず本体とは別の小さなプログラムで「2 台の PC 間でハッシュ値を指定して画像を 1 枚受け渡す」検証を行う。
