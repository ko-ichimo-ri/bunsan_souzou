# 画面の構築に egui を使う

- 日付：2026-09-24
- 状態：採用

## 背景

試作品では、コマの中にマウスで線を引く・消す・素材を貼る・コマを並べる画面が必要。Rust の画面ライブラリには egui・iced・Slint・Tauri（Web 技術）などがある。

## 判断

画面の構築に egui（アプリケーションの枠組みは eframe）を使う。

## 理由

- 毎フレーム画面全体を描き直す「即時モード」方式で、状態の持ち方が単純。初心者にも扱いやすい。
- 線や図形を直接描く API（`Painter`）があり、お絵描きツールの試作に向く。
- マウス入力の座標・押下状態を簡単に取得できる。
- Windows・macOS・Linux・Web に対応している。

## 影響

- 標準のフォントに日本語が含まれていないため、日本語フォントを読み込む処理が必要。
- 本格的な描画性能が必要になった段階で、描画部分を wgpu などへ移すことを検討する。
