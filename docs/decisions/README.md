# 設計判断の記録

技術選定や方針など、版をまたいで効いてくる判断とその理由を残す場所です。1 件 1 ファイルで書きます。

判断を変えるときは、新しい記録を追加し、古い記録の状態を「置き換え」にして新しい記録へのリンクを書きます。

## ファイル名

`連番4桁-内容を表す短い英語.md`

例：`0002-language-rust.md`

## テンプレート

```markdown
# タイトル

- 日付：YYYY-MM-DD
- 状態：提案 / 採用 / 置き換え（→ 新しい記録へのリンク）

## 背景

## 判断

## 理由

## 影響
```
