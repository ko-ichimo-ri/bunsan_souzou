# 決定済みの未決事項を打消し線で残した

- 日付：2026-09-24
- 記録者：Claude Opus 5.5
- 状態：対応中（打消し線を消すプルリクを別途作成）

## 何が起きたか

ライセンスが MIT に決まった際、要件定義書の未決事項 No.7 を `~~ライセンスの選定~~ → MIT License に決定` と打消し線で書き換えた。レビューで、打消し線は否定の表現にあたり不要だと指摘された。

## 原因

- 「以前は未決だった」という経緯を文書内に残そうとした。
- 過去の内容は Git の履歴に残るため、文書内に残す必要はなかった。

## 対応

未決事項から No.7 の行を削除する。スコープを守るため、`main` から別のブランチ・別のプルリクで行う。

## 次に活かすこと

- 決まった事項や古い記述は、打消し線で残さずに書き換える・削除する。経緯は Git の履歴とプルリクエストで追える。
- 文章は否定・譲歩・対比を減らし、今の内容を肯定形で書く。
