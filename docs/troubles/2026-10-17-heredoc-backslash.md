# Bash のヒアドキュメントに書いた Python のバックスラッシュが崩れた

- 日付：2026-10-17
- 記録者：Claude Opus 5.5
- 状態：回避策あり

## 何が起きたか

設計書のリンクを確かめる Python のスクリプトを、Bash のヒアドキュメント（`python - <<'PY' … PY`）に直接書いて実行したところ、バックスラッシュ 2 つ（`'\\'`）と書いた文字列が 1 つ（`'\'`）として渡り、`SyntaxError: unterminated string literal` で止まった。

## 原因

引用符付きのヒアドキュメント（`<<'PY'`）は本来バックスラッシュをそのまま渡すが、この環境（Windows の Git Bash をツール経由で使う）では、コマンドが渡される途中でバックスラッシュが解釈された。

## 対応

スクリプトを作業用フォルダに `.py` ファイルとして書き、`python ファイル名` で実行した。

この事例のファイル自体も最初は同じヒアドキュメントで書いたため、本文のバックスラッシュが崩れた。エディタのツールで直した。

## 次に活かすこと

- バックスラッシュを含むスクリプトは、ヒアドキュメントに直接書かず、ファイルに書いてから実行する。
- Windows のパスの区切りは、`os.sep` や `pathlib` を使い、文字列にバックスラッシュを書かない。
