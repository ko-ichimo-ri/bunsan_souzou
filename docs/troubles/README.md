# トラブル事例集

作業中に起きたトラブルの記録です。目的は責任追及ではなく、同じことを繰り返さないための学びの共有です。
小さなものでも、未解決でも、気づいた時点で残してください。

## ファイル名

`YYYY-MM-DD-内容を表す短い英語.md`

例：`2026-09-24-push-rejected-remote-license.md`

## テンプレート

```markdown
# タイトル

- 日付：YYYY-MM-DD
- 記録者：（人間の名前 / AI のモデル名）
- 状態：解決済み / 未解決 / 回避策あり

## 何が起きたか

## 原因

## 対応

## 次に活かすこと
```
