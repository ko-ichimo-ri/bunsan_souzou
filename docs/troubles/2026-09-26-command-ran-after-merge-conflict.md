# 取り込みで競合したのに、続くコマンドまで実行した

- 日付：2026-09-26
- 記録者：Claude Opus 5.5
- 状態：解決済み

## 何が起きたか

仕様書のブランチに要件定義のブランチを取り込む（`git merge`）と同時に、仕様書のファイルを移動する（`git mv`）コマンドを、PowerShell で `;` でつないで 1 回で実行した。取り込みで README が競合したが、続く `git mv` も実行され、移動が取り込み途中の状態に混ざった。続く `git commit` は競合のため失敗した。

## 原因

- PowerShell の `;` は、前のコマンドが失敗しても次のコマンドを実行する。
- 取り込みは競合しうる操作なのに、結果を確かめる前に次の操作をつないでいた。

## 対応

1. `git mv` で移動を元に戻した（取り込み途中の状態から移動を取り除いた）。
2. README の競合を解消して、取り込みを完了した。
3. 改めてファイルを移動し、別のコミットにした。

履歴の書き換えは行っていない。

## 次に活かすこと

- 取り込み（`git merge`）のように失敗や競合がありうる操作の後は、結果を確かめてから次の操作に進む。
- コマンドをつなぐときは、失敗したら止まる形にする。Bash では `&&`、PowerShell では `if ($?) { ... }` を使う。
