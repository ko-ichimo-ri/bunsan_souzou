# イメージビデオの生成スクリプトで不具合が 2 件あった

- 日付：2026-09-24
- 記録者：Claude Opus 5.5
- 状態：解決済み

## 何が起きたか

1. 分岐と統合の場面で、分岐した上側の履歴系統の線が表示されず、線がまっすぐ 1 本だけ描かれた。
2. 動画全体を書き出したところ、開始直後に `ValueError: font size must be greater than 0` で停止した。

## 原因

1. 折れ線上の位置を求める関数が、始点からの距離の代わりに「最後の線分の中での距離」を返していた。呼び出し側はそれを始点からの距離として使っていた。
2. タイトル文字を拡大しながら表示する処理で、拡大率がごく小さい瞬間に文字サイズが 0 になった。事前の確認では代表的な時刻の静止画だけを書き出しており、開始直後の時刻を含めていなかった。

## 対応

1. 関数が始点からの距離を返すように修正した。
2. 文字サイズの下限を 1 にした。

## 次に活かすこと

- 動画やアニメーションは、代表的な時刻の静止画で見た目を確かめる方法が有効だった（不具合 1 はこれで見つかった）。
- 静止画の確認には、場面の切り替わり直後など、値が 0 や端になる時刻も含める。
