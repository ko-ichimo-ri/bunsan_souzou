# AAC に圧縮した後の音量が上限ぎりぎりになった

- 日付：2026-09-24
- 記録者：Claude Opus 5.5
- 状態：解決済み

## 何が起きたか

イメージビデオの音楽を、最大音量が上限の 90% になるよう整えて WAV に書き出した。MP4（AAC）に圧縮した後に測ると、最大音量が -0.1 dB になり、音割れの一歩手前だった。

## 原因

AAC などの非可逆圧縮では、波形の形が少し変わり、元の波形より山が高くなることがある。WAV の段階で上限近くまで音量を上げていたため、圧縮後に余裕がなくなった。

## 対応

仕上げの音量を上限の 80% にして書き出し直した。圧縮後の最大音量は -0.7 dB になった。

## 次に活かすこと

- 圧縮して配る音声は、書き出す前の段階で上限まで 1 dB 以上の余裕を残す。
- 音量の確認は、圧縮した後のファイルで行う（`ffmpeg -af volumedetect`）。
