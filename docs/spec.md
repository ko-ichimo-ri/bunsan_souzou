# 分散創造 仕様書（v0.1.0 試作品）

| 項目 | 内容 |
| --- | --- |
| 対象の版 | v0.1.0（試作品） |
| 作成日 | 2026-09-24 |

[要件定義書](requirements.md) の各要件を、利用者から見た動きとして具体化します。各節の見出しに、対応する要件 ID を書きます。内部の作りは [設計書](design.md) にあります。

## 1. 画面構成

```
+--------------------------------------------------+
| メニューバー                                     |
+----------+------------------------+--------------+
| ツール   | キャンバス             | 履歴パネル   |
| バー     | （1 ページ）           |              |
+----------+------------------------+--------------+
| 状態表示                                         |
+--------------------------------------------------+
```

| 領域 | 内容 |
| --- | --- |
| メニューバー | 「作品」「素材」メニューと「保存」ボタン |
| ツールバー | 使う道具を 1 つ選ぶ。選んだ道具で、キャンバス上のマウス操作の意味が決まる |
| キャンバス | 1 ページを、ウィンドウに収まる大きさで表示する |
| 履歴パネル | 履歴系統の選択、分岐・統合、メッセージ欄と「履歴更新」、履歴一覧、アップロード・継続ダウンロード |
| 状態表示 | 操作の結果とエラーを 1 行で表示する |

### 1.1 道具

| 道具 | マウス操作 | 対応 |
| --- | --- | --- |
| ペン | コマの中をドラッグして線を引く | R-001 |
| 消しゴム | ドラッグでなぞった線を消す | R-002 |
| コマ | 空いた場所をドラッグしてコマを作る。コマをクリックして選び、移動・大きさ変更する | R-010・R-011 |
| 表示範囲 | コマの中をドラッグして中身の表示位置を動かす。ホイールで拡大・縮小する | R-012 |
| 素材 | 貼った素材をドラッグして移動し、角をドラッグして大きさを変える | R-021 |

## 2. 作品の管理（R-050・R-051）

### 2.1 新しい作品を作る

1. メニュー「作品 → 新規作成」を選ぶ。
2. 作品を置くフォルダを選ぶ。
3. 空のページが表示される。作品フォルダは同時に Git リポジトリになる。

### 2.2 作品を開く

メニュー「作品 → 開く」で作品フォルダを選ぶ。

### 2.3 保存する

- 「保存」ボタンまたは Ctrl+S で、編集内容を作品フォルダに保存する。
- ウィンドウのタイトルに、保存していない変更があることを「*」で示す。
- 保存していない変更があるまま閉じようとしたときは、保存するかを確認する。

## 3. ページとコマ

### 3.1 ページ

- 1 作品につき 1 ページ。大きさは B5 縦（182 × 257 mm）の比率で固定。

### 3.2 コマを作る・消す（R-010）

- 道具「コマ」で、ページ上のコマのない場所をドラッグすると、ドラッグした範囲に長方形のコマができる。
- コマを選んで Delete キーを押すと、コマとその中身が消える。

### 3.3 コマを動かす・大きさを変える（R-011）

- 道具「コマ」でコマをクリックすると選択状態になり、枠の四隅に操作点が表示される。
- コマの内側をドラッグすると移動、四隅の操作点をドラッグすると大きさが変わる。
- コマの中身は、枠の位置・大きさを変えても変わらない（R-014）。

### 3.4 表示範囲を変える（R-012）

- 道具「表示範囲」でコマの中をドラッグすると、中身全体の表示位置が動く。
- マウスホイールで、中身の表示を拡大・縮小する。
- 中身のうちコマの枠からはみ出した部分は表示しない。

### 3.5 読み順（R-013）

- 各コマの左上に読み順の番号を表示する。
- 道具「コマ」でコマを選び、「前へ」「後へ」ボタンで読み順を入れ替える。
- 新しく作ったコマは最後の番号になる。

### 3.6 コマ割りとコマ内容の保存（R-014）

- コマ割り（コマの位置・大きさ・表示範囲・読み順）と、コマ内容（線・貼った素材）は別々のファイルに保存する。
- コマ割りだけを変えた場合、保存してもコマ内容のファイルは変わらない。コマ内容だけを変えた場合も同様。

## 4. 描画

### 4.1 線を引く（R-001）

- 道具「ペン」でコマの中をドラッグすると、マウスの軌跡に沿って線が引かれる。
- 線の色は黒、太さは固定。
- ドラッグを始めたコマに線が属する。コマの外にはみ出した部分は表示しない。

### 4.2 線を消す（R-002）

- 道具「消しゴム」でドラッグすると、マウスの軌跡に触れた線が線ごと消える。
- 消しゴムの当たり判定は、マウス位置を中心とした小さな円とする。

## 5. 素材

### 5.1 素材一覧

- メニュー「素材 → 素材一覧」で、手元にある素材を縮小画像つきで一覧表示する。
- 手元にある素材は、P2P で受け取った素材と、自分で公開した素材。

### 5.2 素材を貼る（R-020・R-022）

1. 道具「コマ」で、素材を貼りたいコマを選ぶ。
2. 素材一覧から素材を選び「貼る」を押す。または「素材 → 画像ファイルから貼る」で PNG ファイルを選ぶ。
3. 素材がコマの中央に貼られる。
- 貼った素材は作品フォルダ内にコピーされ、作品フォルダだけを別の PC に渡しても同じ見た目になる。
- 重なり順は、素材が下、線が上。

### 5.3 素材を動かす・大きさを変える（R-021）

- 道具「素材」で素材をドラッグすると移動する。
- 素材の四隅をドラッグすると、縦横比を保ったまま大きさが変わる。
- 素材を選んで Delete キーを押すと、素材がコマから外れる。

## 6. 素材の P2P 配布

### 6.1 公開する（R-030）

1. メニュー「素材 → 公開」で PNG ファイルを選ぶ。
2. 素材 ID（英数字の文字列）が表示される。「コピー」ボタンでクリップボードにコピーできる。
3. 素材 ID を相手に伝える（チャット・メールなど）。
- 公開した素材は素材一覧にも入る。
- アプリケーションを起動している間、公開した素材を相手が受け取れる。

### 6.2 受け取る（R-031・R-032）

1. メニュー「素材 → 受け取る」を選び、素材 ID を貼り付けて「受け取る」を押す。
2. 受け取りが終わると、素材が素材一覧に入る。
- 受け取ったデータは、素材 ID に含まれるハッシュ値と照合する。一致しない場合は破棄し、状態表示にエラーを出す。
- 公開側のアプリケーションが起動していない場合や、つながらない場合は、状態表示にエラーを出す。

## 7. 分散バージョン管理

### 7.1 履歴更新（R-040）

1. 履歴パネルのメッセージ欄に、変更内容のメモを書く。
2. 「履歴更新」を押す。
- 保存していない変更があれば、先に保存してから履歴更新する。
- 変更がない場合は、状態表示に「変更はありません」と出す。
- 初めて履歴更新するときに、作者名とメールアドレスを尋ねる。入力内容は作品フォルダに記録し、次回から使う。

### 7.2 履歴一覧（R-041）

- 履歴パネルに、今の履歴系統の履歴を新しい順に表示する。各行にメッセージと日時を表示する。

### 7.3 過去の状態を見る・戻す（R-042）

- 履歴一覧の行をクリックすると、その時点の状態をキャンバスに表示する。表示中は編集できず、画面上部に「過去の状態を表示中」と出る。
- 「今の状態に戻る」で表示を元に戻す。
- 「この状態に戻す」を押すと、作品をその時点の状態にし、「（メッセージ）の状態に戻す」という新しい履歴を作る。それまでの履歴はすべて残る。

### 7.4 分岐と切り替え（R-043）

- 「分岐」を押し、新しい履歴系統の名前を入力すると、今の状態から新しい履歴系統ができ、そちらに切り替わる。
- 履歴系統の一覧から選ぶと、その履歴系統に切り替わり、キャンバスの表示も切り替わる。
- 保存していない変更や、履歴更新していない変更があるときは、切り替える前に履歴更新するよう促す。

### 7.5 統合（R-044）

1. 「統合」を押し、取り込む履歴系統を選ぶ。
2. 選んだ履歴系統の変更を、今の履歴系統に取り込む。
- 競合がなければ、統合の履歴ができて完了する。
- 競合した場合は、競合したファイル（コマ割り・コマ内容など）の一覧を表示する。ファイルごとに「こちらを採用」「あちらを採用」を選ぶと統合が完了する。「統合を中止」で統合前の状態に戻せる。

### 7.6 アップロードとダウンロード（R-045）

- **アップロード先の設定**：メニュー「作品 → アップロード先」で、共有フォルダのパスまたは Git のホスティングサービスの URL を設定する。
- **アップロード**：履歴パネルの「アップロード」で、今の履歴系統をアップロード先に送る。
- **初回ダウンロード**：メニュー「作品 → 初回ダウンロード」で、アップロード先と保存先フォルダを指定すると、作品を丸ごと取得して開く。
- **継続ダウンロード**：履歴パネルの「継続ダウンロード」で、アップロード先の新しい履歴を取得して今の履歴系統に統合する。競合時の動きは 7.5 と同じ。

## 8. エラーと起動時の確認

- 起動時に Git がインストールされているかを確認する。見つからない場合は、Git のインストールを案内する画面を表示する（R-101）。
- 操作に失敗したときは、状態表示に理由を表示する。
