# 分散創造 要件定義書（v0.1.0 試作品）

| 項目 | 内容 |
| --- | --- |
| 対象の版 | v0.1.0（試作品） |
| 作成日 | 2026-09-24 |

最終的に目指す姿は [構想](vision.md) にあります。この文書は、構想のうち最低限の範囲を早く形にするための、v0.1.0 の要件を定めます。用語は構想の「3. 用語定義」に従います。

## 1. 目的

分散創造の中心となる次の 4 つを、最小の形で一通りつなげて動かす。

1. コマの中に線を描く
2. コマ割りとコマ内容を別々に管理する
3. 素材を P2P で受け渡し、作品に貼る
4. 作品を分散バージョン管理する

## 2. 完成の定義

次の流れが最後まで通れば、v0.1.0 は完成とする。PC A と PC B は、同じ PC 上で 2 つのアプリケーションを起動した状態でもよい。

1. PC A で画像ファイルを素材として公開し、素材の ID を得る。
2. PC B で素材の ID を入力し、素材を受け取る。
3. PC B で新しい作品を作り、コマを 2 つ配置する。
4. コマ 1 に線を引き、一部を消す。コマ 2 に受け取った素材を貼る。
5. コマ 1 の表示範囲（トリミング）を変える。
6. 履歴更新する。
7. 新しい履歴系統を分岐し、コマ割り（コマの位置・大きさ）を変えて履歴更新する。
8. 元の履歴系統に戻り、コマ 1 に線を描き足して履歴更新する。
9. 2 つの履歴系統を統合し、コマ割りの変更と線の描き足しが両方反映されていることを確かめる。
10. 作品をアップロードし、PC A で初回ダウンロードして、同じ見た目で表示されることを確かめる。

## 3. 機能要件

「構想」列は、対応する構想の要件 ID です。

### 3.1 描画

| ID | 要件 | 構想 |
| --- | --- | --- |
| R-001 | コマの中にマウスで線を引けること。線の色は黒、太さは固定とする | F-DRAW-02 |
| R-002 | 消しゴムでなぞった線を、線ごと消せること | F-DRAW-02 |

### 3.2 コマ割り

| ID | 要件 | 構想 |
| --- | --- | --- |
| R-010 | 1 ページの中に長方形のコマを追加・削除できること | F-MANGA-02 |
| R-011 | コマの位置と大きさを変えられること | F-MANGA-02 |
| R-012 | コマに表示するコマ内容の範囲（位置・拡大率）を変えられること（トリミング） | 4.4.1 |
| R-013 | コマの並び順（読み順）を変えられること | F-MANGA-09 |
| R-014 | コマ割りとコマ内容を別々のファイルに保存し、コマ割りを変えてもコマ内容のファイルが変わらないこと | F-MANGA-03・F-MANGA-05 |

### 3.3 素材

| ID | 要件 | 構想 |
| --- | --- | --- |
| R-020 | PNG 画像を素材としてコマに貼り付けられること | F-ASSET-01 |
| R-021 | 貼り付けた素材の位置と大きさを変えられること | F-ASSET-01 |
| R-022 | 貼り付けた素材を作品フォルダ内に保存し、作品フォルダだけを渡せば別の PC でも同じ見た目になること | F-ASSET-04 |

### 3.4 素材の P2P 配布

| ID | 要件 | 構想 |
| --- | --- | --- |
| R-030 | 手元の PNG 画像を素材として公開し、素材を指す ID を表示できること | F-P2P-01・F-P2P-03 |
| R-031 | 素材の ID を入力して、公開している PC から素材を受け取れること | F-P2P-01・F-P2P-03 |
| R-032 | 受け取った素材が公開されたものと同一であることを、ハッシュ値で確かめること | F-P2P-03 |

### 3.5 分散バージョン管理

| ID | 要件 | 構想 |
| --- | --- | --- |
| R-040 | 作品の状態を、メッセージを付けて履歴更新できること | F-VCS-01 |
| R-041 | 履歴の一覧（メッセージ・日時）を表示できること | F-VCS-10 |
| R-042 | 過去の履歴の状態を表示し、その状態に戻せること | F-VCS-04 |
| R-043 | 履歴系統の分岐と切り替えができること | F-VCS-03 |
| R-044 | 履歴系統を統合できること。競合した場合は、競合したファイルを表示すること | F-VCS-06 |
| R-045 | 作品を指定の場所（共有フォルダや Git のホスティングサービス）へアップロードし、別の PC で初回ダウンロード・継続ダウンロードできること | F-VCS-08 |

### 3.6 作品の管理

| ID | 要件 | 構想 |
| --- | --- | --- |
| R-050 | 新しい作品を作成し、作品フォルダを指定して開けること | ― |
| R-051 | 編集内容を作品フォルダに保存できること | NF-05 |

## 5. v0.1.0 の対象外

次の項目は構想に含まれ、v0.1.0 の後の版で扱う。

- レイヤー、筆圧、線の色・太さの変更、画素単位の消しゴム
- 取り消し・やり直し（v0.1.0 では履歴から戻す）
- 複数ページ、長方形以外のコマ
- テキスト・吹き出し
- 履歴候補上げ、差分の視覚的な比較、電子署名
- 画像・PDF の書き出し
- 素材の作者・利用条件の記述、素材の版の管理
- 素材の限定公開・暗号化・匿名化、自前の中継サーバー、ピアの自動発見・検索
- 拡張機能

## 6. 前提と制約

- 技術構成は [設計判断の記録](decisions/) に従う（Rust・egui・JSON・git コマンド・Iroh）。
- P2P 配布は、本体に組み込む前に、2 台の PC 間でハッシュ値を指定して画像を 1 枚受け渡す検証用プログラムで動作を確かめる。
