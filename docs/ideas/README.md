# アイデア集

思いついたアイデアを気軽に置く場所です。完成度は問いません。1 件 1 ファイルで書きます。

構想に採用したアイデアは [vision.md](../vision.md) に反映し、ファイルの状態を「採用」にします。

## ファイル名

`YYYY-MM-DD-内容を表す短い英語.md`

例：`2026-09-24-timelapse-export.md`

## テンプレート

```markdown
# タイトル

- 日付：YYYY-MM-DD
- 提案者：（人間の名前 / AI のモデル名）
- 状態：検討中 / 採用 / 見送り

## 内容

## 実現したいこと・うれしいこと

## メモ
```
